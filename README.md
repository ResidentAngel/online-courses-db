# Образовательная платформа «Онлайн-Курсы» (PostgreSQL + Go)

Веб-приложение для автоматизации образовательной платформы, предоставляющей доступ к теоретическим материалам, практическим задачам по программированию с автоматической проверкой кода, экзаменационным тестам и биллингу платных услуг. Проект разработан в рамках дисциплины «Базы данных».

* **Стек технологий:** Go (Golang), PostgreSQL 16 (`pgx/v5`, `database/sql`), Docker & Docker Compose, HTML5/CSS3
* **Диаграмма БД:** [Ссылка на Яндекс.Диск](https://disk.360.yandex.ru/d/kzr2Ez13myk7Mw)

---

## 1. Архитектура базы данных (16 таблиц, 3НФ)

База данных спроектирована в третьей нормальной форме (3НФ) и разделена на 6 логических блоков:

| Логический блок | Таблицы в PostgreSQL | Назначение |
| :--- | :--- | :--- |
| **Учетные записи и сессии** | `users`, `userentry` | Хранение профилей пользователей, ролей, `bcrypt`-хэшей паролей и журнала авторизаций/активности. |
| **Учебный контент** | `page`, `tips` | Страницы теоретических лекций и подсказки к практическим задачам. |
| **Задачи и технологии** | `problem`, `language`, `languagetoproblem` | Каталог алгоритмических задач, справочник компиляторов и связь `M:N` доступных языков для каждой задачи. |
| **Проверка кода** | `coderun`, `codesubmit` | Фиксация пробных отладочных запусков (`coderun`) и финальных отправок в тестирующую систему (`codesubmit`). |
| **Тестирование** | `test`, `testquestion`, `testanswer`, `teststart`, `testresult` | Конфигурация тестов, банк вопросов и ответов, фиксация начала попытки и сохранение итогового балла. |
| **Партнеры и биллинг** | `company`, `problem_to_company`, `transactiontype`, `transaction` | Привязка брендированных задач к компаниям-партнерам (`M:N`) и история финансовых операций. |

---

## 2. Реализованные роли пользователей

Интерфейс приложения разделен на 4 ролевые вкладки:
1. **Студент (`student`):** изучение теории (`page`), просмотр подсказок (`tips`), пробный запуск кода (`coderun`), отправка решения на проверку (`codesubmit`), прохождение тестов (`teststart` $\rightarrow$ `testresult`).
2. **Преподаватель (`teacher`):** создание задач (`problem`), привязка разрешенных языков (`languagetoproblem`) и компаний (`problem_to_company`), публикация лекций (`page`), наполнение тестов вопросами (`testquestion`) и ответами (`testanswer`).
3. **Представитель компании (`company`):** просмотр агрегированной статистики успешных решений по брендированным задачам своей
